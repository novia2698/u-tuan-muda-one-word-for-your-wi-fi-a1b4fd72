One word for the Wi-Fi, as lived: **Ghosted**. The connection is there one second and gone the next — mid-call, mid-download, mid-game — no warning, no goodbye. Your Wi-Fi ghosted you, and now it is the network's name.

## Run it

```sh
node main.ts
```

The program writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output/entry.txt` by default) and prints it. It is deterministic: every run writes the same word.

## The word

**Ghosted** — picked against the judge's brief: one word, funny at once, true to how home Wi-Fi actually behaves, a fresh angle on the familiar dropout instead of the obvious "Buffering" or "Loading", and instantly gettable with no explanation. The winning word becomes the sponsor's Wi-Fi network name.
